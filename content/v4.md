WHG v4.0 is planned for **early 2027**. It will bring together, in one coordinated launch, features
that are currently in beta testing.

| | |
|---|---|
| **Atlas** | a map-first way to explore WHG's ~47 million place records through space and time, grouping records that describe the same place as you explore |
| **Collaborative Workbench** | Map your Data (matching a table of places to WHG), Place Collections, Itineraries and Gazetteer Groups, built in the browser and shared with a team |
| **Suggesting corrections** | reviewed, attributed corrections to published records |
| **Toponym phonetics** | sounds-alike matching across spellings and scripts |
| **Standardised place types** | Getty AAT types across every source |
| **Citations and credit** | dataset citations and contributor credit by role |

## The data model

v4 is built on an **attestation** model. Every statement about a place (a name, a location, a date
range, a type, a relationship) is a separate claim, attributed to its source, with its own dates
and certainty. The model is formalised as
[PLATO](https://github.com/pelagios/place-attestation-ontology), the Place Attestation Ontology,
which WHG uses alongside the **Linked Places Format (LPF)** for data coming in and going out.

The model is stored in **PostgreSQL/PostGIS**, with **Elasticsearch** for search: the stack WHG
already runs. That was a deliberate, tested choice; see [System Architecture](./v4/system-architecture.md).
