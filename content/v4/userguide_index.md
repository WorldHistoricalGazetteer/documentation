# Draft v4 User Guide

```{admonition} Draft: for review during beta testing
:class: important
This is a **draft** of the user guide for **WHG v4.0**, planned for early 2027. It describes features
that are still in beta, and it will change. It does **not** replace
[Guides & Tutorials](../guides.md), which document the WHG site as it is today.

Beta testers: please check it against what you see, and report anything wrong, unclear or missing
through the beta snag list (see the [Beta Testing Plan](../v3-3/beta-testing.md)).
```

This guide covers WHG v4 from a user's point of view: exploring places, matching your own data,
building collections with colleagues, improving published records, and getting data in and out.
