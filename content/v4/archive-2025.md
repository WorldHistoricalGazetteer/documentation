# Archive: the 2025 v4 Design

```{admonition} Superseded
:class: warning
These pages record the **2025 design** for WHG v4: a planned move to a graph database (ArangoDB),
a migration to a Kubernetes cluster at Pitt CRC, and a user guide written for that design. Both
the database move and the migration were abandoned in 2026, and the user guide describes a
product that was never built. The pages are kept unchanged as a record. For current WHG v4, see
[WHG v4.0](../v4.md).
```
